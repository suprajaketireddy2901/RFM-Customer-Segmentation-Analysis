# RFM Customer Segmentation Analysis

## Project Overview

This project analyzes customer purchasing behavior using **RFM (Recency, Frequency, Monetary) analysis** in Microsoft Excel.

The analysis uses customer transaction data to understand purchasing behavior and identify different customer segments based on their recency, purchase frequency, and monetary value.

## Business Objective

The objective of this analysis is to:

* Understand customer purchasing behavior
* Identify recently active customers
* Identify frequent customers
* Identify high-value customers
* Segment customers based on RFM characteristics
* Generate insights that can support customer-focused business decisions

## RFM Analysis

RFM stands for:

| Metric        | Definition                               |
| ------------- | ---------------------------------------- |
| **Recency**   | How recently a customer made a purchase  |
| **Frequency** | How frequently a customer made purchases |
| **Monetary**  | How much a customer spent                |

These three dimensions are used together to understand customer value and purchasing behavior.

## Excel Analysis

The project also includes **PivotTable analysis** to summarize and explore the transaction data.

The analysis covers areas such as:

* Customer-level analysis
* Product-level sales analysis
* Location-wise sales analysis
* Transaction analysis
* Sales/value analysis

The analysis can help identify:
